# 学習ログ

## 手順
1. `docs/learning-log.md` がなければ `# 学習ログ` の見出しだけで作成する
2. 末尾に下記の形式で 1 エントリ追記する(既存の記述は変更しない)
3. 内容は、そのセッションで実際に行ったことだけを書く

## 形式
```markdown
## YYYY-MM-DD Phase N: <トピック>
- やったこと: <1〜3 項目>
- 分かったこと: <概念・コマンド>
- つまずき/未解決: <あれば>
- 次回: <次にやること>
```

## 例
```markdown
## 2026-10-29 Phase 0: 環境構築
- やったこと: uv で .venv 作成、geopandas をインストール
- 分かったこと: QGIS 同梱の Python と .venv の Python は別物
- つまずき/未解決: なし
- 次回: 地理院タイルを QGIS に読み込む
```
