    ⑤ バッファ・カバー率	10km バッファ → 重なりを統合 → 市区町村と交差 → 面積比	バッファ、ディゾルブ、交差
        カバー率の定義: 市区町村ごとに「10 km バッファに含まれる面積 ÷ 市区町村の面積」(0〜1)。面積は EPSG:6675 の平面上で計算する
        - [x] ⑤-1 検算の基準を決める(QGIS 操作なし)(11/17: バッファ 1 つ ≈ 309.0 km²(円 314.16 km² より約 1.6% 小さい)/ 融合後のカバー率は 0〜1 / 交差した面積の合計は 5,169.09 km² 以下)
            - 変電所 1 か所の 10 km バッファの面積は、円なら約何 km² か。QGIS のバッファは円を多角形で近似する(セグメント数 = 4 分の 1 円あたりの辺の数、初期値 5)ため、円より大きくなるか小さくなるかを考える
            - バッファの重なりを統合しないまま市区町村と交差すると、市区町村ごとのカバー率はどうなりうるか(1 を超えることはあるか)
            - 統合したバッファと市区町村を交差した面積の合計は、最大で何 km² になりうるか(③-2 の面積合計 5,169.09 km² との関係)
        - [x] ⑤-2 バッファを作り、重なりを統合する
            A. ツールボックスで「バッファ」(英語名 Buffer、「ベクタジオメトリ」グループ)を開く
            B. 入力レイヤ = substations_6675、距離 = 10000、単位 = メートル、セグメント数 = 5(初期値のまま。Phase 2・3 でも同じ値を使う)、「結果を融合する」(Dissolve result)のチェックは外す
            C. 出力を data/processed/substation_buffer10km_6675.gpkg に保存する(228 件になるか確認)✅ 11/17(228 件、1 つの面積 309,016,994 m² = 正二十角形の理論値と一致)
            D. ツールボックスで「融合」(③-2 と同じツール)を開き、入力レイヤ = substation_buffer10km_6675、基準属性は指定しない
            E. 出力を data/processed/substation_buffer10km_dissolved_6675.gpkg に保存する(1 件になるか確認)
            F. フィールド計算機などで、substation_buffer10km_6675 の面積の合計と substation_buffer10km_dissolved_6675 の面積を比べ、差(重なっていた面積)を記録する
            ✅ 11/17: 融合後 1 件・7,291,783,627 m² / 融合前の合計 70,455,874,632 m²(228 × 309,016,994)/ 差 63,164,091,005 m²(融合後は融合前の約 10%)/ 融合後は県の面積 5,169.09 km² より大きい(海・県外へのはみ出し)
        - [x] ⑤-3 市区町村と交差し、カバー率を計算する
            A. ツールボックスで「フィールド計算機」(英語名 Field calculator)を開き、入力レイヤ = n03_substation_count_6675、フィールド名 = muni_area_m2、式 = `area($geometry)` で市区町村の面積を追加する(出力は一時レイヤでよい。④ の n03_substation_count_6675.gpkg は上書きしない)
            B. ツールボックスで「交差」(英語名 Intersection、「ベクタオーバーレイ」グループ)を開き、入力レイヤ = A の出力、オーバーレイレイヤ = substation_buffer10km_dissolved_6675 で実行する
            C. B の出力の地物数を確認する。69 件未満なら、バッファと少しも重ならない市区町村が交差の結果から消えている
            ✅ 11/17: A の出力(レイヤ名 muni_area、一時レイヤ)の muni_area_m2 合計 5.16909e+09 m² で ③-2 と一致 / B の出力(レイヤ名 muni_buffer_intersection、一時レイヤ)は 69 件 → E は不要 / 覆われない部分の例: 豊田市南東部・新城市北西部・設楽町南西部の境(三河山間部)
            D. フィールド計算機で B の出力に covered_m2 = `area($geometry)`、cover_ratio = `"covered_m2" / "muni_area_m2"` を追加する
            E. C で 69 件未満だった場合: 「属性で結合(テーブル結合)」(英語名 Join attributes by field value、`結合` で検索)で、A の出力(69 件)に D の結果を N03_007 で結合し、結合できなかった行の cover_ratio を `coalesce("cover_ratio", 0)` で 0 にする
            F. 69 件の結果を data/processed/n03_coverage_6675.gpkg に保存する
            ✅ 11/17: D は 2 回のフィールド計算機(covered_m2 → 一時レイヤ covered、cover_ratio → n03_coverage_6675.gpkg)/ 豊橋市 918,142,941.46 m²・838,676,895.60 m²・0.9134
            - 面積の式は `$area` ではなく `area($geometry)` を使う。`$area` はプロジェクトの楕円体の設定に従って楕円体面上で計算するため、GeoPandas(平面上の計算)と値がずれる
        - [x] ⑤-4 結果を確認する(11/17)
            A. n03_coverage_6675 の地物数が 69 件で、N03_007 に重複がないか ✅(件数・ユニーク数とも 69)
            B. 統計パネルで cover_ratio の最小・最大が 0〜1 に収まり、covered_m2 の合計が ⑤-1 の上限を超えていないか ✅ 11/17(最小 0.8048・最大 1 / covered_m2 合計 4.98417e+09 m² ≤ 5.16909e+09 m² / 県全体のカバー率 ≈ 0.964)
            C. 県全体のカバー率(covered_m2 の合計 ÷ muni_area_m2 の合計)を計算し、④ で NUMPOINTS が 0 だった 12 市区町村のカバー率を見る(隣の市区町村の変電所でカバーされているか)
            D. 県境に近い市区町村では、隣の県(岐阜・三重・静岡・長野)の変電所がデータに入っていないため、カバー率が実際より低く出ている可能性があることを地図で確かめる
            ✅ C: NUMPOINTS = 0 の 12 件の cover_ratio は 0.8048〜1(隣の市区町村の変電所のバッファでカバーされる)/ 最小は南知多町(0.8048、半島の先端と島)
            ✅ D: 南知多町は陸で他県と接しないため県境の影響は小さい。北設楽郡など他県と接する市区町村は、他県の変電所を含めていないためカバー率が低めに出ている可能性がある(結果の限界)
